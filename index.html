Hubungkan dashboard ke GitHub

Agar tombol di dashboard bisa menjalankan cek dan menyimpan kata kunci, perlu token GitHub (sekali saja di tiap perangkat):

  1. Buka GitHub → Fine-grained token baru
  2. Repository access: Only select repositories → rank-mitrateknik
  3. Permissions: Actions = Read and write, Contents = Read and write
  4. Generate, salin, lalu tempel di bawah

Token hanya disimpan di browser perangkat ini, tidak dikirim ke mana pun selain GitHub.
